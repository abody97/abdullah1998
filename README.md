# نظام إدارة الموظفين والمعدات - ولاء المستقبل للمقاولات

## نظرة عامة
نظام إلكتروني شامل لإدارة الموظفين والمعدات في مؤسسة ولاء المستقبل للمقاولات. يوفر النظام واجهة سهلة الاستخدام باللغة العربية لإدارة جميع العمليات الإدارية المتعلقة بالموظفين والمعدات.

## المميزات الرئيسية

### 📊 لوحة التحكم الرئيسية
- عرض إحصائيات شاملة للموظفين والمعدات
- إجمالي الموظفين والموظفين النشطين
- إجمالي المعدات والمعدات العاملة
- واجهة سهلة للتنقل بين الأقسام

### 👥 إدارة الموظفين
- **إضافة موظف جديد** مع جميع البيانات المطلوبة:
  - الاسم الكامل
  - رقم الهوية/الإقامة وتاريخ الانتهاء
  - الجنسية
  - المهنة/المنصب
  - رقم الجوال
  - تاريخ بدء العمل
  - حالة الموظف (على رأس العمل، إجازة، نهاية خدمة)
  - إمكانية رفع المستندات والصور

- **عرض قائمة الموظفين** مع:
  - جدول شامل لجميع الموظفين
  - إمكانية البحث والفلترة
  - فلترة حسب الحالة والمنصب
  - عرض الحالة بألوان مميزة

- **ملف الموظف الشخصي**:
  - عرض كامل لجميع بيانات الموظف
  - عرض المستندات المرفوعة
  - تاريخ إضافة الموظف

- **تعديل وحذف** بيانات الموظفين

### 🔧 إدارة المعدات
- **إضافة معدة جديدة** مع:
  - اسم المعدة
  - رقم اللوحة/الرقم التسلسلي
  - نوع المعدة
  - حالة المعدة (تعمل، صيانة، معطلة)
  - تاريخ الشراء
  - إمكانية رفع صور المعدة والمستندات

- **عرض قائمة المعدات** مع:
  - جدول شامل لجميع المعدات
  - إمكانية البحث والفلترة
  - فلترة حسب الحالة والنوع
  - عرض الحالة بألوان مميزة

- **ملف المعدة**:
  - عرض كامل لجميع بيانات المعدة
  - عرض الصور والمستندات المرفوعة
  - تاريخ إضافة المعدة

- **تعديل وحذف** بيانات المعدات

### 🔍 البحث والفلترة
- بحث سريع في أسماء الموظفين وأرقام الهوية
- فلترة الموظفين حسب الحالة والمنصب
- بحث في أسماء المعدات وأرقام اللوحات
- فلترة المعدات حسب الحالة والنوع

### 📁 إدارة المستندات
- رفع وعرض صور المستندات للموظفين
- رفع وعرض صور المعدات والمستندات
- معاينة الصور قبل الحفظ
- تخزين آمن للمستندات

## التثبيت والإعداد

### 1. رفع الملفات
```bash
# رفع جميع الملفات إلى مجلد الموقع
- index.html
- .htaccess
- README.md
```

### 2. إعداد الأمان (مهم جداً)
قم بتعديل ملف `.htaccess` لتفعيل حماية IP:

```apache
# ألغ التعليق وعدل عناوين IP التالية:
<RequireAll>
    Require ip 192.168.1.100    # عنوان IP للمكتب
    Require ip 192.168.1.101    # عنوان IP إضافي
    # أضف المزيد حسب الحاجة
</RequireAll>
```

### 3. إعداد HTTPS (موصى به)
```apache
# في ملف .htaccess، ألغ التعليق عن:
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
```

### 4. اختبار النظام
- افتح المتصفح وانتقل إلى عنوان الموقع
- تأكد من ظهور لوحة التحكم الرئيسية
- اختبر إضافة موظف وإضافة معدة

## الأمان والحماية

### 🔒 حماية الوصول
- **IP Whitelisting**: السماح بالوصول فقط من عناوين IP محددة
- **عدم وجود نظام تسجيل دخول**: الوصول مباشر للمدير فقط
- **حماية الملفات الحساسة**: منع الوصول للملفات الهامة

### 🛡️ رؤوس الأمان
- حماية من XSS attacks
- حماية من Clickjacking
- حماية المحتوى
- تشفير البيانات المنقولة

### ⚠️ تنبيهات أمنية مهمة
1. **يجب تفعيل IP Whitelisting قبل النشر**
2. **استخدم HTTPS دائماً في البيئة الإنتاجية**
3. **قم بعمل نسخة احتياطية من البيانات بانتظام**
4. **راقب سجلات الوصول للنظام**

## النسخ الاحتياطي
البيانات محفوظة في `localStorage` المتصفح. للحصول على نسخة احتياطية:

```javascript
// في وحدة تحكم المتصفح
console.log(localStorage.getItem('employees'));
console.log(localStorage.getItem('equipment'));
```

## الاستخدام

### إضافة موظف جديد
1. انقر على "الموظفين" في القائمة العلوية
2. انقر على "إضافة موظف جديد"
3. املأ جميع البيانات المطلوبة
4. ارفع المستندات (اختياري)
5. انقر على "حفظ"

### إضافة معدة جديدة
1. انقر على "المعدات" في القائمة العلوية
2. انقر على "إضافة معدة جديدة"
3. املأ جميع البيانات المطلوبة
4. ارفع صور المعدة والمستندات (اختياري)
5. انقر على "حفظ"

### البحث والفلترة
- استخدم مربع البحث للبحث السريع
- استخدم قوائم الفلترة للتصفية حسب الحالة
- استخدم فلترة المنصب أو النوع للتصفية المتقدمة

## الدعم والصيانة

### الصيانة الدورية
- تحقق من سجلات الوصول شهرياً
- قم بعمل نسخة احتياطية من البيانات أسبوعياً
- راقب استخدام مساحة التخزين

### حل المشاكل الشائعة
1. **البيانات لا تظهر**: تأكد من تفعيل JavaScript
2. **لا يمكن رفع الصور**: تحقق من حجم الملف
3. **النظام بطيء**: امسح ذاكرة التخزين المؤقت
